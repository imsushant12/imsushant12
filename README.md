#### 🛠️ [Transpiler-Pro](https://github.com/openSUSE/transpiler-pro) - Documentation Migration Pipeline *(sole developer)*

Designed and built an end-to-end Markdown/MDX → AsciiDoc migration pipeline for SUSE documentation, using a **Shield → Convert → Repair → Audit** architecture: structural conversion, NLP-based linguistic repair (spaCy), Antora cross-reference routing, and content-parity auditing. Owned architecture, implementation, testing, CI/CD, and deployment end-to-end - later adopted from a personal repository into the **openSUSE GitHub organization**.

**Stack:** Python, spaCy, Pandoc, Vale, Typer, PyTest, GitHub Actions
